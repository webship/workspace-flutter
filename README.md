# @webship.co/workspace-flutter

Flutter for the [Webship Workspace](https://github.com/webship/workspace) dashboard: a builder that builds a Flutter
web app in a container of its own (the Flutter SDK, pinned, in the app's container) and serves the built app, the
Flutter step pack wired into the workspace's testing setup of that app, and its AI items. The workspace is
container-based (DDEV by default).

The builder, the tests and CI come with the first release, `1.0.0`.
